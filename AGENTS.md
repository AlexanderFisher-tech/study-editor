# AGENTS.md — Antigravity Study Editor

Instructions and invariants for coding agents working in this repository. For the full design specification, block schemas, styling tokens, and alternatives evaluated, read [docs/architecture.md](docs/architecture.md).

## Overview

This package compiles a Notion-style interactive study note editor into two static assets:
- `dist/study-editor.min.js` (self-contained IIFE bundle, auto-mounts on `#study-root` using `<script id="note-data" type="application/json">`)
- `dist/study-editor.min.css` (Light/Dark theme tokens, Visual Weight Ladder, pure CSS `:has()` Hover-to-Isolate, native HTML5 `popover` reference tables)

Notes are generated by Gemini Canvas as thin HTML shells pointing to pinned GitHub tags via jsDelivr:
`https://cdn.jsdelivr.net/gh/AlexanderFisher-tech/study-editor@vX.Y.Z/dist/study-editor.min.{js,css}`

## Tech Stack & Project Layout

- **Runtime:** Preact (`preact`) + TypeScript (`strict: true`). Zero other runtime dependencies.
- **Bundler:** Vite (`vite.config.ts`) in IIFE library mode with `cssCodeSplit: false`.
- **Tests:** Vitest (`tests/unit/*.test.ts`) + Playwright (`tests/e2e/*.spec.ts` served via `scripts/static-server.mjs`).

## Non-Negotiable Invariants

1. **Keep `dist/` Tracked in Git (jsDelivr `/gh/` Requirement):**
   `cdn.jsdelivr.net/gh/AlexanderFisher-tech/study-editor@vX.Y.Z/dist/...` reads files directly from the Git tag tree—not GitHub Release binary attachments. Never add `dist/` to `.gitignore`, and always rebuild and commit `dist/study-editor.min.js` and `dist/study-editor.min.css` before tagging a release.
2. **Bundle Size & Dialog Policy (`npm run verify:bundle`):**
   - Combined gzipped size of `dist/study-editor.min.js` + `dist/study-editor.min.css` must remain `<= 40 KB` (`40960` bytes).
   - Never call `window.alert()`, `window.confirm()`, or `window.prompt()`. Use inline two-step confirmation popovers and `role="status"` toasts.
3. **Strict Inline HTML Sanitization (`src/utils/sanitizer.ts`):**
   - Allowed inline tags only: `<span data-color|data-note|data-mask|data-bind>`, `<u>`, `<code>`, `<strong>`, `<br>`.
   - Legacy shorthand tags (`<red>...</red>`, `<dot data-note="...">`) must continue normalizing to `<span data-...>` on load.
   - Code generics like `List<T>` and `Map<K, V>` must escape safely to `&lt;...&gt;` rather than being dropped by HTML5 parsing.
   - Never assign raw unsanitized strings from `#note-data` or clipboard paste into `innerHTML`.
4. **Schema Resilience & Flat Block Model (`src/types/schema.ts`):**
   - Keep all block types flat (no recursive nested block trees).
   - `UnknownBlock` must always preserve its original `type` and arbitrary unknown properties during edits and sync patches. Use the `isKnownBlock(block)` type guard before switching on `block.type` so TypeScript strict narrowing stays sound.
5. **Preact Timing & DOM Gotchas (Verified in Chromium E2E):**
   - In `EditableRichText.tsx`, keep DOM `innerHTML` sync and `focusRequest` focusing inside `useLayoutEffect` (not async `useEffect`), otherwise fast typing after `# ` Markdown conversion drops keystrokes when switching block components.
   - In `store.ts`, read `docRef.current` inside keyboard-triggered callbacks (`triggerSync`, `triggerExportMarkdown`) so `Cmd+Shift+S` never reads stale state between Preact effect flushes.
   - In `FloatingToolbar.tsx`, track `subPanelRef.current` synchronously alongside state so opening the micro-dot note input never races with `mouseup`/`selectionchange`.
   - In `study-editor.css`, hide `[data-note]::before` with `display: none` at rest (`display: block` on `:hover`), not `opacity: 0` alone, so the invisible tooltip does not expand the span's hit box or pollute accessibility text.
6. **Composite Study Widget Scope (YAGNI Boundary):**
   - `tabs`, `spotlight`, and `peek` are structurally authored by Gemini in `#note-data`; users edit their text content inline. Do not add in-editor modal CRUD builders for table columns, spotlight line indices, or tab panel creation unless the spec is updated.
   - Do not add backend sync servers, OAuth flows, or KaTeX loaders into the v1 core bundle.

## Commands & Verification

Run before committing or tagging any change:

```bash
npm run typecheck       # tsc --noEmit (strict mode)
npm run test:unit       # Vitest unit tests (sanitizer, sync/storage reconciliation, markdown export)
npm run build           # Typecheck + Vite IIFE library build into dist/
npm run verify:bundle   # Enforces <= 40 KB combined gzipped size & zero alert()/confirm() calls
npm run test:e2e        # Playwright Chromium E2E against examples/sample-note.html (uses static-server.mjs)
npm test                # Runs unit tests -> build -> verify:bundle -> E2E tests
```

## Release Workflow

```bash
npm test
git add dist/study-editor.min.js dist/study-editor.min.css
git commit -m "Release vX.Y.Z"
git tag -a vX.Y.Z -m "Release vX.Y.Z"
git push origin main
git push origin vX.Y.Z
git ls-tree vX.Y.Z dist/
```

Verify both jsDelivr endpoints return HTTP 200 (the repository must remain public for jsDelivr `/gh/` access):
- `https://cdn.jsdelivr.net/gh/AlexanderFisher-tech/study-editor@vX.Y.Z/dist/study-editor.min.js`
- `https://cdn.jsdelivr.net/gh/AlexanderFisher-tech/study-editor@vX.Y.Z/dist/study-editor.min.css`
